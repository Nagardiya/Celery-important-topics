Parallel Tasks — add_numbers aur multiply_numbers ko parallel run karna
Multiple Workers / Concurrency — workers ke through parallel processing
Task Queue Concept — task ko queue mein bhejna aur worker ka queue se task lena

Nested / Dependent Tasks — ek task ke result/condition ke basis par doosra task chalana
Redis as Celery Broker — Redis ko task queue/broker ke liye use karna
